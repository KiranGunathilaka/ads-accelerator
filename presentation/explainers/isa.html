Instruction set

Instruction set architecture, v1.1

The format, all 32 instructions, the addressing modes that make the sliding window cheap, and the exact program the simulator runs.

Instruction format

OPCODE[31:27] · 5 bits
DST[26:22] · 5
SRC1[21:17] · 5
SRC2[16:12] · 5
IMM12[11:0] · 12 bits

Every instruction is 32 bits with the same fields, so decode is one cycle of wiring. OPCODE[4:3] selects one of four groups of eight. The meaning of a register field depends on the opcode:

Field kindCodes 0–7Code 8+
vector sourceV0–V78–15 = W0–W7, the window chunks (VMAC only)
scalarS0–S78 = ZERO
addressA0–A78 = ZERO (base for AGU_SET)
CSRindex in IMM12[3:0]

v1.0 used one global 2-bit tag per field. Its CSR tag (10) overlapped bit 3 of the index, so only 8 of the 16 CSRs were reachable. Typing fields by opcode removes the tag bits entirely.

Addressing modes

ModeExampleUsed for
Post-incrementVLD V4, [A2]+16walking through w, y, e, g in 16-word chunks; scalar stores with +1
CircularAGU_SET A0, A7, X_RING, circ=1input rings: the pointer wraps inside a 512-word aligned region
Sliding windowWSLIDE [A0], len=64next row (Phase 1) or column (Phase 3) of X with one memory read

Why these three are enough. After storing w reversed, every access in the algorithm is either an aligned 16-word chunk, a single word, or “the same window moved by one”. There are no strides, gathers or unaligned vectors, so the AGU is an adder and a mask.

The microprogram

One pass per block: 78 instructions, 312 bytes of IMEM. The encodings are the assembler's actual output.

Phase 1 inner loop, instruction by instruction

LOOP    128, 7                       ; 128 rows, 7-instruction body, zero overhead
  VMAC.C  W0, V4, sh=7               ; VACC  = x_full[i+1..i+16] × w_rev[0..15]
  VMAC    W1, V5, sh=7               ; VACC += next 16 taps
  VMAC    W2, V6, sh=7
  VMAC    W3, V7, sh=7               ; 64 taps; 48 MACs per VMAC across 3 PEs
  VREDUCE S1, sh=23, rnd=1, sat16=1  ; 16 lanes → y[i] in Q1.15
  WSLIDE  [A0], len=64               ; window → row i+1 (one new sample)
  SST     S1, [A3]+1                 ; y[i] → memory

Phase 3 has the same shape. The window is 128 samples (column k = x_full[k+1..k+128]), e sits in V0–V7, there are 8 VMACs per column, and VREDUCE shifts by 7 to divide by B.
